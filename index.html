PYTHON LISTS

ما هي القائمة List؟

الـ List هي واحدة من أهم هياكل البيانات في Python. تسمح لك بتخزين عدة قيم داخل متغير واحد، ويمكن تعديل عناصرها وإضافة عناصر جديدة وحذفها وترتيبها. 

students = ["Ali", "Sara", "Omar"]
[ ] رمز إنشاء القائمة
0 أول Index
Mutable قابلة للتعديل
Ordered تحافظ على الترتيب

04

تعديل عناصر القائمة

لأن List قابلة للتعديل Mutable، نستطيع تغيير قيمة أي عنصر. 

names = ["Ali", "Sara", "Omar"]

names[1] = "Lina"

print(names)
🔑 نحدد العنصر باستخدام الـ Index ثم نعطيه قيمة جديدة.
05

إضافة وحذف العناصر

append()

يضيف عنصراً في نهاية القائمة. 

names.append("Omar")
insert()

يضيف عنصراً في Index محدد. 

names.insert(1, "Sara")
remove()

يحذف أول عنصر يطابق القيمة. 

names.remove("Sara")
pop()

يحذف عنصراً حسب Index ويعيد قيمته. 

deleted = names.pop(1)

أهم الدوال والعمليات

الأمر الوظيفة مثال
append() إضافة في النهاية list.append(5)
insert() إضافة في مكان معين list.insert(1, 5)
remove() حذف قيمة list.remove(5)
pop() حذف حسب Index list.pop(0)

len() عدد العناصر len(list)
count() عدد مرات تكرار قيمة list.count(5)
index() معرفة موقع قيمة list.index(5)
clear() تفريغ القائمة list.clear()
copy() نسخ القائمة list.copy()

الـ Slicing يسمح لك بأخذ جزء من القائمة دون الحاجة إلى أخذ كل العناصر. 

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])

[20, 30, 40]

08

القوائم مع For Loop

واحدة من أكثر الاستخدامات شيوعاً للقوائم هي المرور على جميع عناصرها. 

fruits = ["Apple", "Banana", "Orange"]

for fruit in fruits:
    print(fruit)

استخدام enumerate()

إذا أردت الحصول على الـ Index والعنصر معاً، يمكنك استخدام enumerate(). 

fruits = ["Apple", "Banana", "Orange"]

for index, fruit in enumerate(fruits):
    print(index, fruit)

11

List Comprehension

طريقة مختصرة وقوية لإنشاء القوائم باستخدام تعبير واحد.

مثال بسيط

بدلاً من كتابة حلقة كاملة، يمكن إنشاء قائمة جديدة بطريقة مختصرة. 

squares = [x * x for x in range(1, 6)]

print(squares)

# [1, 4, 9, 16, 25]

مع شرط 

numbers = [1, 2, 3, 4, 5, 6]

even = [
    x for x in numbers
    if x % 2 == 0
]

print(even)
⚡ List Comprehension قوية جداً، لكن لا تستخدمها بطريقة تجعل الكود صعب القراءة. وضوح الكود أهم من اختصاره.
12

نسخ القوائم

يجب الانتباه عند نسخ القوائم حتى لا تعدّل القائمة الأصلية عن طريق الخطأ. 

numbers = [1, 2, 3]

copy_numbers = numbers.copy()

copy_numbers.append(4)

print(numbers)
print(copy_numbers)

❌ تجنب 

copy = numbers

هنا المتغيران يشيران إلى نفس القائمة.

✓ الأفضل 

copy = numbers.copy()

إنشاء نسخة مستقلة من القائمة.

أخطاء شائعة عند استخدام Lists

IndexError

محاولة الوصول إلى Index غير موجود.

numbers[10]
ValueError

محاولة حذف قيمة غير موجودة باستخدام remove().

numbers.remove(100)
TypeError

استخدام نوع بيانات بطريقة غير مناسبة.

numbers + 5
خطأ منطقي

استخدام Index خاطئ رغم أن الكود يعمل.

names[1]
15

List أم Tuple؟

من المهم معرفة الفرق بين أشهر بنيتين لتخزين البيانات في Python.

List 

numbers = [1, 2, 3]
  • قابلة للتعديل
  • تستخدم [ ]
  • مناسبة للبيانات المتغيرة

Tuple 

numbers = (1, 2, 3)
  • غير قابلة للتعديل
  • تستخدم ( )
  • مناسبة للبيانات الثابتة
